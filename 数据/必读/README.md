# 必读 · 加载总纲

> 任何 AI 在回答李东盛（Else）的个人历史、人物关系、身体生活、职业项目或超我 Skill 问题前，**先按本目录 README → 01 → 02 → 03 → 04 顺序读完**，再进入 DLC，最后按需检索原始日志。

## 1. 加载顺序（三层）

| 层 | 内容 | 何时读 |
|---|---|---|
| **第一层 · 必读** | 本目录 `README.md` → `01_身份与关系基线.md` → `02_证据协议.md` → `03_数据地图.md` → `04_日志更新协议.md` | 每次对话，按序自执行 |
| **第二层 · DLC** | `../dlc/01`–`08` + `../dlc/README.md` + `../dlc/manifest.json` | 必读之后，逐份加载 |
| **第三层 · 按需** | 部分 DLC（`../dlc/数据快照/`、`../dlc/超我Skills快照/`）+ `../../日志/` 全部 156 篇 + 参考层 | 问题涉及对应主题时再读 |

## 2. 权威优先级（回答冲突时）

用户当前明确说明 > **必读** > DLC 补丁 > 主分析文档（`../AI问答与个人助手知识库分析.md`）> 原始日志 > 快照 / AI 转存 / OCR。

## 3. 硬规则

1. 不把情绪、心理学描述固化为诊断或人格标签。
2. 不把 2026-10 的快照当作当前事实；动态字段（学期、实习、城市、关系、主线）先确认再答。
3. 引用格式统一为 `[日期｜标题｜日志ID]`。
4. 私有文件（`else_super_ego_v2.md`）只本地检索，不外传。

## 4. 更新责任

- **日志更新（新增 / 修订 / 补图）** → 按本目录 `04_日志更新协议.md` 的 A→E 清单执行。
- **本人新确认** → 先改对应 DLC 补丁，再回填本目录 `01` / `02`。
- **每次改动** → 更新本文件 `version` 与日期。
