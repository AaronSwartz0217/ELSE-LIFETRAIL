## 6. 技术方向演变解读

以下是基于仓库创建/更新时间与网站项目说明的推断：

1. **早期试验与展示**：2023 年的 `NSHXG`、2025 年的 `Sponza` 主要呈现早期网页或图形试验痕迹。
2. **2026 年春季扩展到完整应用**：个人网站、`AI-Voice-Assistant`、`.NET_Chat`、`NTU_DigitalTwin`、`NTU_Building` 和《物魄奇谭》显示出从课程/展示项目向完整系统整合的扩张。
3. **2026 年中期形成游戏与 Agent 双线**：UE5/GAS、Houdini/WFC、Blender 自动化与 `Else-SuperEgo-Skills` 同时出现，说明作者开始把个人方法论工程化。
4. **2026 年后期向工具链和底层图形靠拢**：Unity 角色流程插件、UI 生产工作流、GLTF 捕获、磨砂玻璃 Shader、D3D12 延迟渲染与 DLSS 链路，体现出从“做一个项目”向“搭建可复用生产与渲染系统”的迁移。
5. **MCP 与跨工具整合**：`freemocap_MCP` 代表把外部开源工具接入 Agent/工作流的探索，但它是 Fork，未来应通过 commit diff 判断本人修改量。

这条路径可以概括为：**广泛应用开发 → 游戏全栈与技术美术 → 自动化工具链 → 图形渲染与 Agent/MCP 系统化**。这是阶段性解释，不能代替用户当前求职主线。
