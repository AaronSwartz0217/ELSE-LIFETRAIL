# 个人知识库 DLC

本目录是 `AI问答与个人助手知识库分析.md` 的补丁层，补充用户本人确认的个人信息、人物映射、公开作品链接、本地超我 Skills 快照，以及一条 AI 综合的十年时间线（07）。它位于 [必读](../必读/README.md) 层之后加载。

## 文件结构

- `01_个人信息与关系时间线补丁.md`：身份、教育信息、实名人物映射、关系时间线和异性偏好（自述）。
- `02_个人网站与GitHub项目索引.md`：个人网站页面、作品集项目、25 个公开仓库及更新规则。
- `03_超我Skills本地资料说明.md`：本地仓库状态、四步机制、文件哈希、隐私和助手接入规则。
- `04_关系补充说明_本人确认.md`：四段关系（许铭杨、姚春雨、祝开欣、张琰）的情感投入与心理影响澄清，修正“影响大=喜欢深”的推断。
- `05_身体生活家庭与经济状况_本人确认.md`：身体与运动、作息烟酒饮食、家庭结构与事件、经济独立与求职城市。
- `06_大学阶段补充_本人确认.md`：2023 入学至今的大学主线（社团、转专业、游戏开发与被利用、加班与分红、两段恋情），补齐日志未记录的盲区。
- `07_十年时间线_详版含推断.md`：2005–2026 的**一条连续主线**，以 8 个转折点分段（不按自然年切节），行文内逐处标注「实据 / 推断」；附录含四条并行线（读书 / 感情 / 社团 / 职业）与出入待确认项。**AI 综合，非本人确认。**
- `08_语气与对话风格补丁.md`：模仿本人语气时的语域分层（独白体 / 对话体 / 书面意象体）、句式特征、词汇表与首要禁令。语域禁令为本人确认，句式特征为 AI 推断。
- `09_家族事件与经济纠纷_本人确认.md`：爷爷去世后的房产与遗产处置、家庭债务（父亲入狱旧债、母亲以用户名义借钱）、与家人的关系，以及用户自述的家庭影响归因（约 70%）。
- `超我Skills快照/`：2026-10-03 读取到的 4 个 Markdown 文件副本。
- `数据快照/`：GitHub 公共 API、网站文件树和机器可读个人信息补丁。

## 隐私边界

本目录包含真实姓名、生日、学校、关系史和私有心理 Skill 数据，只用于用户本地个人助手。`超我Skills快照/else_super_ego_v2.md` 明确属于私有文件，不应上传、公开、粘贴到第三方服务或加入公开仓库，除非用户再次明确授权。
